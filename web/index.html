The game runs in Wine inside Boxedwine (an x86 emulator compiled to WebAssembly) and every frame is drawn by Mesa's software OpenGL on the CPU, so expect a few frames per second. The first start takes several minutes; don't reload while the screen is black.

The game comes activated with the key from the itch.io page (THET-ALEV-LEFR-USWO). If you played an earlier, unactivated version of this page in this browser, open it once with ?reset=1 added to the address to drop that old save.

Sound starts after your first mouse click on the game. Progress is kept in this browser (IndexedDB). Add ?sound=false to the URL to mute.
